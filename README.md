# Velora Estates 🏙️

A cinematic luxury real estate frontend experience inspired by Dubai’s premium property market.

Velora Estates is a high-end responsive web application built to showcase modern luxury properties with immersive visuals, smooth interactions, elegant typography, and premium UI/UX experiences.

This project is designed as a world-class portfolio piece for frontend development and UI/UX design roles in Dubai.

---

# ✨ Features

- Cinematic hero sections
- Luxury-inspired UI design
- Smooth page transitions
- Responsive layouts
- Interactive property browsing
- Elegant animations with Framer Motion
- Glassmorphism effects
- Modern component architecture
- Mobile-first optimization
- High-performance frontend setup

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/velora-estates.git
```

Navigate into the project:

```bash
cd velora-estates
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

# 📦 Build For Production

```bash
npm run build
```

Production files will be generated inside:

```bash
dist/
```

---

# 🌐 Deployment

This project is deployed using FTP shared hosting.

Upload the contents of the `dist` folder to your hosting directory using FileZilla or any SFTP client.
